# Краткая демонстрация (1–2 минуты)

[Открыть сервис](https://violettancl.github.io/illustration-composer/) в приватном окне. Ключ не требуется.

| Время | Действие | Ожидаемый результат |
|---|---|---|
| 0:00 | «По смыслу»: Кэшбэк за каждую покупку → Собрать | Композиция из готовых компонентов |
| 0:20 | «По названиям»: книга, телефон, 2 монеты, фоновые наушники | 5 объектов |
| 0:40 | Выбрать слой, переместить, повернуть, дублировать, изменить порядок, удалить | Редактор меняет сцену |
| 1:00 | Переключить L/S и загрузить examples/palettes/sunset.json | Композиция перекрашивается |
| 1:20 | Скачать SVG | Файл содержит векторные контуры и отдельные группы |
| 1:40 | Импортировать скачанный SVG в Figma | Проверить редактируемость групп вручную |

Примеры: [кэшбэк](../examples/compositions/01-cashback-1200x630-L-violet.svg), [экзамен](../examples/compositions/02-exam-1080x1350-L-peach.svg), [командная работа](../examples/compositions/03-teamwork-1080x1080-S-mint.svg).

## Автоматическая проверка

```bash
npm ci
npm test
npm run build
npm install --no-save --package-lock=false playwright@1.51.1
npx playwright install chromium
npm run test:browser
```

GitHub Actions запускает проверки перед публикацией. Запись автоматической браузерной демонстрации (.webm) сохраняется как артефакт `browser-demo` в [GitHub Actions](https://github.com/ViolettaNcl/illustration-composer/actions) после выполнения браузерного теста. Этот документ также можно использовать для ручной демонстрации; открытие в Figma требует ручной проверки.
