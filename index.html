ИИ-анализ метафор выкл.

Без ключа работает офлайн-словарь смыслов. С ключом Anthropic метафору разбирает Claude: он только выбирает объекты из каталога, графику не создаёт. Ключ хранится только в этом браузере.

Библиотека

Нажмите «+», чтобы добавить объект на холст. Варианты подгружаются под выбранный размер L/S.

Холст пуст. Введите метафору слева и нажмите «Собрать» или добавьте объекты из библиотеки.

Перетаскивайте объекты мышью. Кружок над рамкой поворачивает объект (с Shift — шаг 15°). Стрелки двигают, Delete удаляет, Ctrl+D дублирует, [ ] меняют слой.
